# RAG lecture source rules

Read `README.md` before editing; it is the authoring and experiment contract.

- Keep one raw triple-quoted Markdown block followed by one code cell per numbered `.py` pair.
- Apply Ponytail full: direct native library calls, small cells, no speculative wrappers.
- Preserve the common corpus/query IDs, shared evaluator and the early Embedding Atlas lesson.
- Do not execute lecture pairs, build/run the notebook, load weights, start servers or train on this laptop without explicit new permission. Static parsing/source review and uv environment preparation are allowed.
- Read `REVIEW.md` when present for outstanding checks. Static review does not establish runtime success.
- Leave the older notebooks and unrelated repository files untouched. Do not commit or push unless requested.
